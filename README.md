# css-responsive-sidebar-navbar
A modern, responsive sidebar navigation dashboard layout built with pure HTML5, CSS3, and Font Awesome featuring smooth transitions and mobile-first responsiveness—without using JavaScript.

## 🛠️ Built With

* **Markup:** [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) (Semantic elements, `<input>`, `<label>`, `<ul>`, `<li>`, `<a>`)
* **Styling:** [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) (CSS Checkbox Hack, Flexbox, Media Queries, CSS Transitions)
* **Icons:** [Font Awesome](https://fontawesome.com/) (Solid and Brand icons)
